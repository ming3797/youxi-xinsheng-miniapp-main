# 有戏新声 · 微信小程序开发版

这次交付是独立的微信原生小程序工程，附微信云开发后端和单文件离线体验页。旧的 React/H5 原型保持原状。

## 现在怎么打开

**直接体验：** 双击 `dist/有戏新声_开发体验版.html`，用 Chrome / Edge 打开。不依赖服务器、不需安装依赖。顶部可切换投稿人、三位示例专家和运营管理员。浏览器数据仅保存在本机；更换浏览器或清理数据不会同步到其他设备。

**查看微信版本：** 在微信开发者工具中导入本文件夹（含 `project.config.json` 的根目录）。当前 `appid` 为 `touristappid`，`miniprogram/config.js` 的 `mode` 为 `demo`，因此不调用微信云环境。不支持游客 AppID 的开发者工具版本可改用自己申请的测试号/真实 AppID，仍保持 `mode: 'demo'`。本机未安装微信开发者工具，因此尚未进行实际微信编译及真机验收。

原生代码无需 npm 构建即可导入。小程序和浏览器离线体验共享业务规则，但二者的本机数据互不相通。

## 体验一条完整流程

1. 顶部选“投稿人 · 我”，提交一份作品，勾选必要声明；需要公开展示时另勾展示授权。
2. 切到“运营管理员”，在“我的 → 运营工作台”找到投稿，分配专家甲和专家乙。
3. 分别切到专家甲、专家乙，在各自评审席填写五项评分和意见；第一位提交前看不到其他人的评分。
4. 两位评分完成后系统自动判断通过/修改/第三位复核。通过奖励积分自动记账，只发一次。
5. 切到运营，符合条件时填写培训安排确认孵化；对已授权作品审核公开正文。
6. 切回投稿人，查看作品、成长权益和积分流水；到创作工坊生成词谱草稿并导出。
7. 打开公开创作者主页提交评论，切换运营审核，再回到主页查看评论。

本地体验为方便操作开放展示和评论；云环境默认关闭这两项，需要配置开关后才开放。当前只有图文展示，作品附件始终私密。

## 已知边界

- 尚无用户提供的微信 AppID、云环境、运营主体和真实专家账号。未部署、未提审、未上架。
- 离线创作使用明确标注的固定模板；已写好真实模型API适配代码，但没有调用真实模型或产生费用。
- 曲谱为C调4/4拍四分音符旋律练习；不保证特定剧种唱腔，不提供完整配器、伴奏或逐字配唱。
- 暂无现金支付、积分充值、现金奖励发放、课程直播、订阅消息和未成年人入驻。
- 免费培训在系统内形成可追踪的“待安排/已安排”记录，真实老师履约及培训资源由运营落实。
- 单类列表当前返回最近200条；正式规模使用前需要分页、查询索引、限流、审计检索、监控、备份及保留期限清理。
- 云数据库和文件安全规则需手动部署。文件类型校验目前为扩展名与实际字节大小，不含杀毒扫描；生产接入需要增加文件安全扫描与内容审核。
- 协议为开发草案，生产前需由运营方补齐正式主体、客服、保存期限、申诉/删除和注销流程。

## 构建与验证

要求 Node.js 18+，业务测试无需安装依赖：

```sh
npm run build
npm test
npm run check
```

`build` 同步共享业务代码至云函数，并重新生成单文件离线体验页。修改 `miniprogram/lib/core.js` 或 `model.js` 后须重新构建。不要单独修改云函数下生成的副本。

`npm run preview` 可在允许监听本地端口的环境打开 `http://127.0.0.1:4326`。本次执行环境禁止监听本地端口，且浏览器工具禁止 `file://`，因此没有进行真实浏览器视觉验收。离线产物已通过脚本语法、独立启动及业务测试；详见 `qa/验收说明.md`。

`npm run qa` 是完整浏览器验收脚本，需 Puppeteer 和可启动的 Chrome。可通过 `OPERA_PUPPETEER_PATH` 指定 Puppeteer 主模块路径；脚本使用临时浏览器上下文，不影响日常浏览数据。它会走查投稿、附件、双评、孵化、公开展示、词谱导出、评论审核、重新打开及320/390/1440宽度布局。本次环境下该脚本未跑通，不能将它视为已完成的浏览器验证。

`npm run release:check` 会在仍使用游客 AppID、离线模式、空云环境或未确认协议时阻止“静态提审检查通过”，避免把开发版当作已具备上架条件。
