# 微信云开发接入指南

本文件是后续操作说明。本次没有替用户注册、购买、部署、发送通知或提交审核。

## 1. 填写工程身份

1. 注册微信小程序，取得真实 AppID。
2. 在微信开发者工具导入本工程，修改 `project.config.json` 的 `appid`。
3. 开通云开发环境。云资源可能计费，由账号负责人选择套餐。
4. 暂时保留 `miniprogram/config.js` 中 `mode: 'demo'`，完成本机流程检查。

## 2. 建集合和权限

- 创建 `opera_records` 集合，填入 `cloud/database.rules.json`：客户端不能直接读写集合，所有数据通过云函数授权访问。
- 在云存储配置 `cloud/storage.rules.json`：只有文件所有者可以读写 `private/` 暂存文件，客户端无法读写 `frozen/` 目录。提交时云函数读取原文件、核对大小、计算摘要并创建冻结副本。评审附件只能通过云函数鉴权后取临时地址。
- 临时地址属于短时访问凭据，不应公开分享；已发出的地址在有效期内不会因撤回页面展示立即失效。
- 按实际查询提示建立组合索引：`kind + ownerId + createdAt`、`kind + published + createdAt`、`kind + profilePublished + createdAt`、`kind + role + createdAt`、`kind + expertIds + createdAt`、`kind + targetId + status + createdAt`、`kind + authorId + published + createdAt`、`kind + status + createdAt`。
- `expertIds` 为数组字段，需验证数组匹配查询及索引在所选云环境正常工作。
- 记录主键由业务ID的SHA-256生成，记录本体另存 `id`。不要依赖数据库 `_id` 作为前端路由参数。

安全规则语法核对来源：[CloudBase安全规则](https://docs.cloudbase.net/storage/security-rules)、[安全规则变量与路径](https://docs.cloudbase.net/rule/learn-rules)。部署后必须用不同微信账号实测隔离，不能仅凭规则文件存在就认为生效。

## 3. 部署云函数

1. 在项目根目录运行 `npm run build` 同步共享代码。
2. 开发者工具中对 `cloudfunctions/studio` 选择上传并部署，云端安装依赖。
3. 云函数运行时选择 Node.js 18 或更高的受支持版本；超时设60秒、内存建议至少512MB（附件最大20MB，逐个处理）。
4. 云函数只信任 `cloud.getWXContext().OPENID`。从控制台不带微信身份直接运行会收到 `UNAUTHENTICATED`，这是预期行为，不要增加允许客户端传入 OpenID 的后门。
5. 将 `miniprogram/config.js` 的 `mode` 改为 `cloud`，填写真实 `cloudEnv`。
6. 真机进入“我的”复制本人账号编号，用于在云函数服务端 `ADMIN_ACCOUNT_IDS` 环境变量配置运营人员（多个以逗号分隔）。该编号是OpenID的SHA-256业务别名，不是原始OpenID。配置后重新登录/刷新角色。其他专家先正常登录，由运营核验后开通。

云端不会导入本地示例数据，也不能通过顶部身份切换器切换角色。

## 4. 模型服务

默认 `AI_ENABLED=false`。没有服务时按钮关闭，后端拒绝生成且不扣积分。

接口适配采用兼容 `POST /chat/completions` 的HTTPS JSON服务。设置 `AI_URL` 为完整接口地址、`AI_KEY` 为服务端密钥、`AI_MODEL` 为模型名称。核对服务商协议、模型登记/备案和内容处理要求后，才设置 `AI_ENABLED=true`。本次未验证任何具体供应商。

适配器仅发送创作主题、剧种、类型及场景，要求JSON输出；返回内容经过本地结构校验。模型调用绝对超时40秒；同一任务重复请求不重复调用。失败退款与成功写入都由事务完成。

云函数进程崩溃时可能留下 `pending` 任务：5分钟后作者可在创作记录检查超时并退回积分。生产建议增加定时补偿任务，不应依赖用户主动点击。当前尚未部署补偿定时器。

## 5. 展示与评论

`SHOWCASE_ENABLED=false` 和 `COMMENTS_ENABLED=false` 为默认配置。按实际微信类目资质、内容审核和运营能力决定开放时间。开关在后端强制执行。

开放展示后仍须作者授权、作品评审通过和运营人工审核；公开投影不返回附件地址、原始所有者编号或私密评审意见。主页仅展示审核后的资料快照。评论先进入待审队列。

真实发布前接入文本/图片/音视频安全审核、速率限制、恶意文件扫描及客服申诉。不能仅修改类目名称绕过实际功能要求。

## 6. 发布前真实环境验收

| 测试 | 期望结果 |
| --- | --- |
| A投稿，B尝试读取私密详情或附件 | 后端拒绝；数据库直接读写也拒绝 |
| A上传后改动暂存文件 | 已提交的服务端冻结副本不变 |
| 未分配专家尝试评审 | 后端拒绝 |
| 专家甲提交前读取乙意见 | 不返回乙意见 |
| 相同请求重复提交或网络重试 | 投稿/扣分/奖励不重复 |
| 模型异常、JSON格式错误或超时 | 积分退回；无伪造成功结果 |
| 云函数中断后再次进入 | 记录显示处理中，超时可恢复积分 |
| 普通用户伪造role或actor | 不能取得运营权限 |
| 取消个人主页和作品展示授权 | 对应公开页立即停止展示 |
| 真实手机导出TXT/MusicXML | 文件内容可读、曲谱可被兼容软件打开 |
| 关闭公开功能与AI开关 | 前端不开放，直接调用后端也拒绝 |

之后补齐运营主体与客服、替换协议草案，完成小程序备案与隐私指引；再运行 `npm run release:check` 并在真实微信开发者工具编译、真机体验后提审。静态检查通过不代表微信平台已审核通过。
